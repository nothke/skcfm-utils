### Downloader
A little GUI for downloading music with yt-dlp. Interfaces directly with ProppFrexx so it can queue and play songs immediately after downloading.

### Arhivator
A GUI for handling the radio's archive
- Scans multiple archive folders and indexes all clips
- Shows all available clips in a zoomable timeline
- Allows playing at any point in the timeline
- Can add labels to time segments, so shows can be tagged (saved to .json so it can be copied easily)
- Export any selected time segment, automatically stitches clips together
